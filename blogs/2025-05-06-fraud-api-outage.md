SEON API’s in the EU region experienced an outage with the Fraud API for 5 minutes between 21:03 to 21:08 UTC on Tuesday May 6th 2025. During this time customers API transactions encountered transaction failures. All SEON APIs are now fully operational, and 24/7 SRE team is closely monitoring to avoid any further occurrences.
